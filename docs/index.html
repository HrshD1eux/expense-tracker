Security & Privacy Under The Hood

Built Like a Vault

We don't ask you to trust a cloud server. Your data never touches a wire.

🛡️

SQLCipher 256-Bit AES

The entire Room database file on your internal storage is transparently encrypted at rest with SQLCipher. Even with physical access or root exploits, the raw database file cannot be read without the hardware key.

🔑

Android Keystore Daemon

Passphrases are generated inside Android's Hardware Security Module (TEE/StrongBox). Keys are shielded against OS lock screen changes with invalidation immunity.

🔐

4-Way Authentication

Choose between Biometrics (Fingerprint/Face unlock), a custom 3×3 Vector Pattern Lock, an Alphanumeric Master Password, or a 4-digit PIN with optional randomized keypad.

⚡

Adaptive Frequency Engine

Categories automatically analyze your spending frequency. Your top 3 most used categories are dynamically elevated to the top for 1-tap logging.

📊

Safe-To-Spend Intelligence

Calculates dynamic daily spending velocity by distributing remaining monthly budget across remaining days, keeping you from overspending before payday.

📱

Jetpack Glance Widget

A high-performance Android home screen widget built with Jetpack Glance. Shows daily and monthly balance with an instant 1-tap expense launcher.
